# Starbucks Calorie Calculator

A premium, mobile-first utility web application built using modern Material Design guidelines to calculate calorie details for Starbucks beverages.

## Features

- **Massive Database:** Includes **83 base drinks** across 7 menu categories (Hot Coffees, Cold Coffees, Frappuccinos, Refreshers, Teas, Hot Chocolates, and Energy Drinks).
- **Comprehensive Customizations:** Allows adding/modifying ingredients (12 milk types, 17 syrups, 8 sauces, 4 powders, and 25 add-ons/toppings).
- **Modern Material Design Vibe:** A visually polished UI featuring a glassmorphic sticky header, tactile action counters, custom toggles, and responsive layouts.
- **Instant Search:** Dynamic search filter to quickly find drinks from the massive list without endless scrolling.
- **Dynamic Breakdown:** Live recalculation of calorie gains/losses as you add or substitute ingredients.

## Technologies Used

- **HTML5** & **Vanilla JavaScript** for core logic
- **Vanilla CSS3** for modern Material Design styling (utilizing CSS variables, backdrop filters, and custom CSS transitions)
- **Google Fonts (Plus Jakarta Sans)** for clean typography

## Getting Started

Simply open `starbucks_calculator.html` in any modern web browser to use the calculator. No server configuration or dependencies are required.
